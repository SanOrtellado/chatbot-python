# Post sugerido para LinkedIn

Hoy comparto un nuevo proyecto para mi portfolio: un chatbot en Python entrenado con un dataset de intenciones.

El objetivo fue entender, de forma practica, como funciona un chatbot clasico basado en procesamiento de lenguaje natural y aprendizaje profundo.

Que incluye:

- Dataset de intenciones, patrones y respuestas.
- Limpieza y preparacion de texto con NLTK.
- Modelo de clasificacion entrenado con Keras/TensorFlow.
- Interfaz conversacional por consola.
- Interfaz web con Streamlit para probar el bot visualmente.
- README con pasos para ejecutar el proyecto.

Aprendizajes principales:

- Como convertir texto en datos que una red neuronal puede procesar.
- Como entrenar un modelo para clasificar mensajes por categoria.
- Como conectar un modelo entrenado con una experiencia conversacional simple.

Este proyecto me ayudo a practicar Python, NLP, redes neuronales simples y organizacion de proyectos para GitHub.

Stack: Python, NLTK, TensorFlow/Keras, NumPy, Streamlit.
